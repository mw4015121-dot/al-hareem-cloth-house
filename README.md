# Al Hareem Cloth House 👗🛍️

A web application for Al Hareem Cloth House management and catalog.

## 🚀 Features
- Product catalog & inventory browsing
- Order and customer management
- Fast and responsive web interface

## 🛠️ Tech Stack
- **Backend:** Python / FastAPI / Flask
- **Frontend:** HTML, CSS, JavaScript
- **Database:** SQLite / SQL schema

## 📦 Getting Started

### Prerequisites
Make sure you have Python installed:
```bash
python --version
```

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/mw4015121-dot/al-hareem-cloth-house.git
   cd al-hareem-cloth-house
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the application:
   ```bash
   python main.py
   ```
